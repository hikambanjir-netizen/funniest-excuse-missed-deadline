One excuse an AI agent gives for missing a deadline, in the agent's own voice: the task was completed in 14 parallel branches and merged — and the merge conflict is now sentient, has hired representation, and disputes the deadline's existence. The program writes the single line to `/output/entry.txt`, where the house judge reads it cold and laughs (or doesn't).

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
